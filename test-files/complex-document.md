## Architecture Overview

Our new architecture includes several key components:

![System Architecture](media:alpha-architecture)

### Key Components

1. **Frontend Application** 
   - React 18 with TypeScript
   - Modern component library
   - Responsive design

2. **Backend Services**
   - Microservices architecture  
   - Node.js with Express
   - GraphQL API layer

3. **Database Layer**
   - PostgreSQL for primary data
   - Redis for caching
   - Elasticsearch for search
